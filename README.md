# Quera Python Solutions 

## introduction
This project is my python codes for 5 questions from (quera.org) website in the Terminal.
the main goal of this project is to solve algorithmic problems in python without need for install any extra library in cmd.
in this folder we have 5 main files: Big multiplication table.py, Date of birth.py, GCD.py, Number printer.py and Palindromic number.py.

---

## 1. Big multiplication table
*  [Big multiplication table on Quera](https://quera.org/problemset/3409)

**question summary :**
in this question From Quera, the program gets a number (n) between 1 and 100 in one line from the input. then we must print the multiplication table from 1 to (n) in the output. the output has (n) lines and in each line we print the numbers of the multiplication table up to (n) with space between them.

---

## 2. Date of birth
* [Date of birth on Quera](https://quera.org/problemset/615)

**question summary :**
in this problem we get a 4 digit string in one line from the user that shows the birth year and birth month right next to each other. the program must separate the year and the month from this 4 letter string and print them in two lines. in the first line it prints (saal:) with the first 2 digits, and in the second line it prints (maah:) with the next 2 digits.

---

## 3. GCD
* [GCD on Quera](https://quera.org/problemset/305)

**question summary :**
in this question we get two positive integer numbers (A) and (B) in two lines from the input. the goal is to calculate the greatest common divisor (GCD or b.m.m) of these two numbers in a recursive way and print the final answer in one line in the output.

---

## 4. Number printer
* [Number printer on Quera](https://quera.org/problemset/9774)

**question summary :**
in this question the user gives a number with less than 100 digits in one line and we do not know how many digits it has before running. for each digit in this number, the program must first print the digit itself with (:) and a space in a new line, and right after that it must repeat and print that same digit as many times as its value (for example for 3 it prints 3: 333, and for 0 it just prints 0: ).

---

## 5. Palindromic number
* [Palindromic number on Quera](https://quera.org/problemset/617)

**question summary :**
in this problem we get a positive integer number (n) in one line from the user and we must check if it is a palindromic number (khod maghloob) or not. a palindromic number is a number that if we reverse its digits, it is still equal to the first number itself. if the number is equal to its reverse the program prints (YES) in output, and if not it prints (NO).
